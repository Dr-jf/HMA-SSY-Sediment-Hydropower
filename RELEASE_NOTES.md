# Version 1.0.0

Core research-code release by Rui Deng.

- 17-predictor, five-member square-root SSY training, with 1,963 expected input records.
- Historical reservoir sediment trapping in 1980–2019, without prehistory.
- Fixed-storage baseline and annual sediment-storage hydropower, with signed net generation differences.
- Private input schemas, explicit units and state/timing assumptions.
- Reproducible core dependencies, artificial tests and an end-to-end artificial smoke check.
- MIT license and citation metadata.

No confidential data, fitted research weights, plots or production results are included. The artificial checks validate software behavior, not manuscript numerical results or the retained scientific assumptions. The code-availability statement and data-access limits are documented separately.
