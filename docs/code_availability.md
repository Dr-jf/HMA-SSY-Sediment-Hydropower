# Code availability and citation

## Suggested manuscript wording

The source code for the 17-predictor SSY model and the historical reservoir sediment-trapping and hydropower workflows is available at https://github.com/Dr-jf/HMA-SSY-Sediment-Hydropower (version 1.0.0, https://github.com/Dr-jf/HMA-SSY-Sediment-Hydropower/releases/tag/v1.0.0) under the MIT License. Installation instructions, input schemas, methodological assumptions and tests using artificial inputs are provided in the repository. Confidential research data and fitted model weights are not distributed; data-access restrictions are described separately in the Data availability statement.

## Software citation

Deng, R. High Mountain Asia SSY, Reservoir Sediment and Hydropower Core Models, version 1.0.0. GitHub. https://github.com/Dr-jf/HMA-SSY-Sediment-Hydropower/releases/tag/v1.0.0 (2026).

## Preparation guidance

Documentation was prepared with reference to [Nature's reporting and code availability policy](https://www.nature.com/nature/editorial-policies/reporting-standards) and [code/software submission guidance](https://www.nature.com/documents/GuidelinesCodePublication.pdf). These describe documentation and sharing expectations; this repository does not claim certification or editorial approval.

The user-selected [Global-river-POC](https://github.com/qqq196988/Global-river-POC) and [Arctic-river-SSC](https://github.com/qqq196988/Arctic-river-SSC) repositories were examined as examples of explaining scientific workflows and external inputs. No source code or data from those repositories is bundled or relicensed here.
